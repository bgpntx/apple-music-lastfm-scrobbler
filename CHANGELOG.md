# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses semantic versioning once releases begin.

## Unreleased

### Added

- Native Swift CLI for Apple Music Last.fm scrobbling.
- Last.fm desktop auth flow.
- Now-playing updates and scrobble submission.
- Scrobble threshold handling.
- Retry queue for failed scrobbles.
- Per-user launchd agent install, uninstall, and status commands.
- Unit tests for Last.fm signatures, scrobble thresholds, and launchd plist generation.
